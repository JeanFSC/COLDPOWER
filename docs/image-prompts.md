## Asset Notes

- Export final production images as WebP.
- Keep product images square where possible for catalog stability.
- Keep hero text-safe space clear.
- Avoid embedded words, fake badges, copied logos, third-party branding (including Carrier logos/wordmarks), and identifiable license plates or storefronts.

## SVG Fallback Assets

For Phase 8, ColdPower uses original SVG fallback illustrations in `public/images/` so the preview no longer depends on weak generic placeholders while final WebP production photography is pending.

Current fallback files:

- `hero-coldpower.svg`
- `category-placeholder.svg`
- `product-placeholder-repuesto.svg`
- `testimonial-placeholder.svg`
- one `cat-<slug>.svg` illustration per category in `src/data/categories.ts`
- one `prod-<slug>.svg` illustration per product referenced in `src/data/products.ts`

When replacing them with final `.webp` photography, preserve the same visual direction: graphite industrial base, orange working light, teal technical accents, no third-party logos, no copied layouts, and clear negative space where UI text overlays the image.
