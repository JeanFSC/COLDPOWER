# ColdPower Design Reference Analysis

## Scope

Reference reviewed: `https://zeroxmotors.pe/`.

This document extracts UX, structure, and composition criteria only. ColdPower must not copy the reference brand, logo, images, text, HTML, CSS, product photos, banners, or code.

## Useful Criteria From The Reference

- Commercial header: visible schedule, search, product navigation, account/cart affordances, and mobile drawer.
- Search priority: product discovery is central because users may search by model, brand, category, or SKU.
- Home structure: hero banner, benefits strip, category grid, sale products, promotional banner, testimonials, FAQ, WhatsApp CTA, and footer.
- Catalog structure: sidebar filters on desktop, category links, brand shortcuts, sorting, pagination, and product grid.
- Product detail structure: breadcrumb, gallery, title, code/model, technical specs table, cotizacion CTA, WhatsApp CTA, location links, payment trust signals, and related products.
- Mobile behavior: compact header, visible search field, drawer menu for categories, stacked product cards, and persistent assisted-commerce CTA.

## What ColdPower Should Improve

- Reduce SEO text density in visible pages and move long descriptive content to structured sections.
- Use stronger accessibility semantics for accordions, buttons, image alt text, and focus states.
- Keep a cleaner visual hierarchy with fewer competing banners.
- Make product cards more technical: SKU, status, origin, compatibility, and direct WhatsApp action.
- Avoid checkout-first assumptions. The first version should prioritize assisted quotation because motor/repuesto compatibility needs validation.

## ColdPower Direction

- Mood: modern industrial, technical, trustworthy, energetic, and commercial.
- Palette: graphite dark surfaces, orange primary action, teal technical accent, light catalog backgrounds.
- Imagery: original product/taller/motor visuals with clean lighting, no copied products or watermarks.
- Typography: Sora for display, Inter for UI/body, monospace for SKU and technical codes.
- Layout: mobile-first, dense but readable catalog, full-width hero later, clear CTAs, and straightforward WhatsApp conversion.

## Non-Copy Rules

- Do not copy the Zerox Motors logo, brand system, text, product photos, banners, icons, HTML, CSS, JavaScript, or WordPress/WooCommerce implementation.
- Do not download images from the reference site.
- Do not reuse product descriptions from the reference.
- Use the reference only as a benchmark for automotive e-commerce structure and conversion flow.
