# CP-027 Bloque B Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Añadir administración editorial, CMS y biblioteca multimedia gobernada al catálogo persistente ColdPower.

**Architecture:** Extender Drizzle de forma aditiva. Mantener `products`, `publication-service`, `catalog-repository`, `company_settings` y `audit_logs` como fuentes y mecanismos únicos; encapsular media en un repositorio de disco con URL API para desarrollo y futura sustitución por objeto remoto.

**Tech Stack:** Next.js 16 App Router, React 19, TypeScript 5, Drizzle ORM, Neon PostgreSQL, Clerk/RBAC, Node Test Runner, Tailwind CSS v4.

## Global Constraints

- `INVENTARIO CATALOGO/ColdPower_Inventario_Final_Validado.xlsx`, hoja `IMPORT_PRODUCTOS`, sigue siendo la única fuente del catálogo público.
- Neon/PostgreSQL es la fuente runtime; no crear arrays persistentes ni mocks de negocio.
- SKU es único, exacto e inmutable; `originalName` nunca se reemplaza por contenido editorial.
- No inventar precios, stock, compatibilidades, teléfonos, correos, promociones ni datos empresariales.
- Toda operación sensible requiere autorización server-side, transacción cuando corresponda e historial append-only.
- Facturación electrónica/SUNAT queda fuera del alcance.
- No hacer commit ni push sin revisar el árbol y contar con autorización explícita.
